# B.R.A.I.N

**Business Response and Automation by Intelligent Networks.**

## The problem

Answering a business question is useful. Booking the meeting, qualifying the lead, or carrying out the next step is usually where the actual work starts.

B.R.A.I.N brings several of those workflows into one AI agents platform instead of leaving each agent as an isolated demo.

## The solution

A business AI platform developed in a final-year project context, combining website support, WhatsApp conversations, scheduling, voice interviews, lead discovery, and administration.

## What it does

- Embeddable website agent with business knowledge.
- WhatsApp customer-support agent and inbox workflows.
- Scheduling and voice-based interview modules.
- Lead discovery and saved-lead workflows.
- Analytics, administration, and subscription integration.

## Engineering highlights

The contribution spans agent/conversation flows, WhatsApp integration, backend behavior, and product integration across modules. The engineering challenge is making account context, tool calls, and user-facing workflows fit together across the platform.

## Technology

Next.js, React, TypeScript, MongoDB/Mongoose, NextAuth, OpenAI Responses and Realtime, Baileys, SERP integrations, Polar.

## Source code

This repository documents the project, its capabilities, and the engineering behind it. The application source code is maintained privately.
